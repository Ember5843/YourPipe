# YourPipe 画中画 (PiPWindow) 接入方案 — typeNode 迁移版

## ⚠️ 给 build agent 的重要说明

**本方案基于 HarmonyOS 官方文档制定**（三篇 PiP 开发指南）。YourPipe 使用第三方 libmpv 播放器（非系统 AVPlayer），经三种方式对比，**必须采用 typeNode 方式**（不是 XComponent 方式，也不是 NDK 方式）。

**核心机制**：创建一个独立的 `typeNode.XComponent(SURFACE)` 节点。正常播放时通过 `NodeContainer` 承载在主播放页；进入 PiP 时系统把节点迁移到 PiP 窗口；退出 PiP 时节点回到主播放页。surfaceId 变化通过 `CustomXComponentController.onSurfaceCreated` 回调自动对接 mpv 的 `setSurfaceID`。

**与之前废弃方案的区别**（重要）：不做"两个 XComponent + SurfaceSwitcher 切换 surfaceId"，不做"pre-warm 规避 onBackground 时序"，不创建独立 PiPContentPage。typeNode 方式由系统原生处理节点迁移和时序，`setAutoStartEnabled` 原生处理 home 键。

## Goal

为 YourPipe 接入系统画中画。设计原则：
1. **typeNode 单节点迁移**：一个 typeNode 节点在主页面和 PiP 窗口间迁移（官方推荐）
2. **onSurfaceCreated 自动对接**：节点 surfaceId 变化时回调注入 mpv
3. **无显式 PiP 按钮**：返回键/home 键根据设置 pipOnReturn 自动触发
4. **setAutoStartEnabled 处理 home 键**：系统原生支持应用返回桌面时自动启 PiP
5. **"后台播放"按钮永远回桌面保活**：不碰 vo，不弹 PiP

## Scope / Non-goals

**Scope：**
- typeNode 方式 PiP（API 12+，SDK 23 满足）
- 控制面板：播放/暂停 + 上一个/下一个（PiPControlType.VIDEO_PLAY_PAUSE / VIDEO_NEXT / VIDEO_PREVIOUS，对应 VIDEO_PLAY 模板）
- 返回键自动弹 PiP（受 pipOnReturn 控制）
- home 键自动弹 PiP（受 pipOnReturn 控制 + setAutoStartEnabled）
- "后台播放"按钮 → moveToBackground
- 设置项 pipOnReturn（默认 true）

**Non-goals：**
- 显式 PiP 按钮
- NDK 方式（需改 C++，不必要）
- PiP 内进度条/手势
- typeNode 的 router 导航子场景（YourPipe 用 Navigation）

## 方式选型依据（为什么是 typeNode）

| 维度 | XComponent 方式 | NDK 方式 | **typeNode 方式** ✅ |
|---|---|---|---|
| 适合 | AVPlayer | NDK 播放器 | **通用（含第三方 NDK）** |
| PiP 画面 | 传主页面 XComponentController | C++ 回调 surfaceId | **typeNode 节点迁移** |
| 改 C++ | 否 | 是（napi_init.cpp） | **否** |
| API | 6.0/Phone/Tablet | **API 20+** | **API 12+** |
| setAutoStart | ✅ | ❌ | ✅ |
| 接入 mpv | 传 componentController | C++ 拿 surfaceId | **onSurfaceCreated 回调 → setSurfaceID** |

typeNode 完美匹配 YourPipe：纯 ArkTS、不改 libmdk_napi 的 C++、onSurfaceCreated 回调天然对接 mpv 的 setSurfaceID、系统原生处理时序。

## Current State And Constraints

### 播放内核（约束）
- libmpv 通过 libmdk_napi NAPI 集成。渲染走 `XComponent(SURFACE)` → surfaceId → NAPI `setVideoSurfaceId` → mpv `wid`。
- `MpvPlaybackEngine.attachSurface` 可重入（每次 bind 新 surfaceId）。
- **后台行为**：mpv 全程渲染，不主动禁用 vo（维持现状软保活）。

### 现有 Surface 绑定（要替换的核心点）
`AVPlayer.ets:611-631` 现在直接用 `XComponent(SURFACE)`，onLoad 时 `controller.setSurfaceID(...)`。
**本方案把这部分替换为 NodeContainer + typeNode**。这是对 AVPlayer.ets 的主要改动。

### 导航与页面（PiP 还原依赖）
- `HdsNavigation(navPathStack)`（`Index.ets:1331`）**当前没有设 id** → 必须新增（PiP 还原需要 navigationId）
- PlayerPage 是 NavDestination，onShown/onHidden（`Index.ets:1377-1382`）会写 playerPageVisible
- onBackPressed（`Index.ets:1387-1400`）三段式
- EntryAbility.onWindowStageCreate（`EntryAbility.ets:89-112`）需增加 makeTypeNode

### 关键约束（来自官方文档）
1. **Navigation 必须设 id**：UIAbility 用 Navigation 管理页面时，需设置 Navigation 控件 id 并传给 PiP 控制器，确保还原时恢复原页面
2. **contentWidth/Height 必须大于 0**：typeNode 方式必须设，否则创建失败；建议传视频实际宽高
3. **关闭 PiP 时检查节点释放**：ABOUT_TO_STOP 时 dispose，避免内存泄漏
4. **主窗口不在前台时，不要在 PiP 回调里做 UI 操作**（如 push/pop），可能不立即执行
5. **setAutoStartEnabled(true)**：应用返回桌面时系统自动启 PiP（home 键场景由系统处理时序，无需 pre-warm）
6. **PiP 单例**：系统同时只允许一个 PiP 窗口
7. **设备限制**：HarmonyOS 6.0 前仅 Phone/Tablet；6.0 起支持 Phone/PC/2in1/Tablet。需 `PiPWindow.isPiPEnabled()` 检测

### ArkTS 约束
- 严格类型，无 any/as
- `moveToBackground` 等价 API 实施时核查（UIAbilityContext）

## Design

### 核心：typeNode 节点迁移（单节点，非双 surfaceId 切换）

```
正常播放：                       进入 PiP：
┌─────────────────────┐         ┌─────────────────────┐
│ PlayerPage           │         │ PlayerPage (占位层)  │
│  └ NodeContainer     │         │  └ (空)              │
│      └ typeNode ←──┐ │         └─────────────────────┘
└────────────────────┘ │         ┌─────────────────────┐
                       │  迁移到→ │ PiP 窗口 (系统)      │
                       └────────→│  └ typeNode          │
                                 │  (系统渲染+控制面板)  │
                                 └─────────────────────┘
退出 PiP：typeNode 迁回 PlayerPage 的 NodeContainer
```

**关键**：typeNode 是一个独立节点对象（`typeNode.XComponent`），可以 appendChild/removeChild 到不同的父节点。系统负责把它迁移到 PiP 窗口渲染。surfaceId 在迁移后会变（新 surface），`CustomXComponentController.onSurfaceCreated(surfaceId)` 回调触发，回调里调 `controller.setSurfaceID(surfaceId)` 把 mpv 的 wid 切到新 surface。

### 交互矩阵（pipOnReturn 默认 true）

| 入口 | pipOnReturn=true | pipOnReturn=false |
|---|---|---|
| **返回键** | startPiP（typeNode 迁到 PiP，主页面保留占位层，app 仍前台） | 现状：release + pop |
| **Home 键** | 系统自动 startPiP（setAutoStartEnabled=true 时） | 回桌面保活（渲染不停） |
| **"后台播放"按钮** | **永远 moveToBackground**（不碰 vo 不弹 PiP） | 同左 |
| **PiP 控制面板恢复** | ABOUT_TO_RESTORE → typeNode 迁回主页面 | — |
| **PiP 控制面板关闭(×)** | 用户关闭 PiP → ABOUT_TO_STOP → typeNode 迁回 + dispose | — |
| **重新打开 app** | Activity 恢复 → 播放页 | 同左 |
| **AVSession 播控** | 只动 PlayerState，不碰 surface | 同左 |

### 模块分层（全部在 entry 层，typeNode 必须用主窗口 UIContext）

```
entry 层
  PiPManager.ets (新)          - 单例：PiPController + typeNode 生命周期 + 控制事件路由
  XCNodeController.ets (新)    - NodeController：makeNode/makeFrameNode 创建 typeNode，add/remove/dispose
  CustomXComponentController.ets (新) - 继承 XComponentController：onSurfaceCreated → setSurfaceID
  EntryAbility.ets (改)        - onWindowStageCreate 增加 makeTypeNode（主窗口 UIContext）
  Index.ets (改)               - HdsNavigation 设 id；onBackPressed 增加 PiP 分支；bindActionHub
  PlayerPage.ets (改)          - 视频区改 NodeContainer(typeNode) + 占位层；onShown/onHidden 管 setAutoStart
  AVPlayer.ets (改)            - 视频渲染层从直接 XComponent 改为 NodeContainer（由 PlayerPage 注入）
  VideoDetails.ets (改)        - "后台播放"按钮 → moveToBackground
  ActionHub.ets (改)           - enterPiP/exitPiP
  PlayerSession.ets (改)       - isPiPActive + PiP 生命周期回调
  PlaybackConfig.ets (改)      - pipOnReturn 字段
mediaservice 层 (不改)
  AvPlayerController.ets       - setSurfaceID 已支持重入（现有）
  MpvPlaybackEngine.ets        - attachSurface 可重入（现有）
```

### typeNode 创建时机（关键）

官方文档明确：typeNode 必须在**主窗口 UIContext** 上创建（不是 PiP 窗口的）。所以：
- `EntryAbility.onWindowStageCreate`（`EntryAbility.ets:99-111`）拿到主窗口后，调 `PiPManager.getInstance().makeTypeNode(uiContext)` 一次性创建全局唯一的 typeNode 节点
- 这个节点对象全局复用，PlayerPage 的 NodeContainer 和 PiP 窗口都用它

### PlayerPage 渲染改造

PlayerPage 的视频区从 `XComponent(...)` 改为 `NodeContainer(PiPManager.getInstance().getXcNodeController())`。typeNode 节点默认 append 到 NodeContainer 里显示。进入 PiP 时（ABOUT_TO_START），从 NodeContainer 移除；退出 PiP 时（ABOUT_TO_STOP），重新 append。

## Execution Sequence

### 阶段 1：PiP 基础设施（entry 层）

1. **新建 `CustomXComponentController.ets`**
   ```typescript
   export class CustomXComponentController extends XComponentController {
     onSurfaceCreated(surfaceId: string): void {
       // typeNode 迁移后 surfaceId 变化，自动对接 mpv
       PlayerSession.getInstance().controller.setSurfaceID(surfaceId);
     }
     onSurfaceDestroyed(surfaceId: string): void { /* log */ }
   }
   ```

2. **新建 `XCNodeController.ets`**（参考官方 navigation/XCNodeController.ets）
   - 继承 `NodeController`
   - `makeNode(context)`: 创建 `FrameNode`，若 typeNode 未创建则 `typeNode.createNode(context, 'XComponent', {type: SURFACE, controller: CustomXComponentController})`，根据 canAddNode appendChild
   - `addNode()` / `removeNode()` / `dispose()` / `setCanAddNode()` / `getNode()`

3. **新建 `PiPManager.ets`**（参考官方 navigation/PipManager.ets，单例）
   - import `{ PiPWindow, typeNode } from '@kit.ArkUI'`
   - 持有 `pipController?: PiPWindow.PiPController`、`xcNodeController: XCNodeController`、`mXComponentController: CustomXComponentController`
   - `makeTypeNode(uiContext)`: 调 `xcNodeController` 在主窗口 UIContext 创建 typeNode（EntryAbility 调用）
   - `init(ctx, videoWidth, videoHeight)`: `PiPWindow.create(config, typeNode)` 创建 PiPController；config 含 context/componentController/templateType=VIDEO_PLAY/contentWidth/contentHeight（必须 >0，用视频实际宽高，用于算 PiP 窗口比例）；注册 stateChange/controlEvent 回调；`setAutoStartEnabled(false)` 默认
   - `startPiP()`: `pipController.startPiP()`
   - `stopPiP()`: `pipController.stopPiP()`
   - `updateContentSize(w,h)`: `pipController.updateContentSize(w,h)`（切视频时更新）
   - `setAutoStart(b)`: `pipController.setAutoStartEnabled(b)`
   - `onStateChange(state, reason)`: 处理 ABOUT_TO_START(removeNode)/STARTED/ABOUT_TO_STOP(dispose + addNode)/STOPPED/ABOUT_TO_RESTORE/ERROR；通知 PlayerSession.setPiPActive；通知 lifeCycleCallback
   - `onActionEvent(control: ControlEventParam)`: VIDEO_PLAY_PAUSE/VIDEO_NEXT/VIDEO_PREVIOUS → 路由到 controller.syncPlay/syncPause 或 PlayQueueManager.next/previous
   - `registerLifecycleCallback(cb)` / `unRegisterLifecycleCallback(cb)` / `unregisterPipStateChangeListener()`
   - `getXcNodeController()` / `getXComponentController()`

4. **修改 `EntryAbility.ets` onWindowStageCreate**（99-112）
   - 拿到主窗口 UIContext 后调 `PiPManager.getInstance().makeTypeNode(uiContext)`
   - 同时存 `AppStorage.setOrCreate('windowId', window.getWindowProperties().id)`（PiP config 可能需要 mainWindowId，实施时按实际 API 确认）

5. **修改 `Index.ets` HdsNavigation 设 id**
   - `Index.ets:1331` 的 `.navDestination(this.PageMap)` 上方增加 `.id('mainNav')`（id 值供 PiP config 的 navigationId 用）

6. **验证阶段1**：编译通过。

### 阶段 2：PlayerPage 接入

7. **修改 `PlayerPage.ets`**
   - 视频区从直接渲染 XComponent 改为 `NodeContainer(PiPManager.getInstance().getXcNodeController())`（占满原视频区尺寸）
   - `@State isPiPActive`（订阅 PlayerSession.setPiPActive 变化）
   - `VideoPlayerContent` Stack：`if (this.isPiPActive) { PiPPlaceholderLayer() }`（占位层盖住视频区，含"画中画播放中" + 恢复提示）
   - `onVideoChange`（282-348）视频加载后：若 PiPController 已创建，调 `PiPManager.updateContentSize(videoWidth, videoHeight)`；若未创建，调 `PiPManager.init(ctx, videoWidth, videoHeight)` 首次创建
   - `onShown`（Index.ets:1377 对应处）：`PiPManager.setAutoStart(pipOnReturn)`（页面可见时允许 home 键自动 PiP）
   - `onHidden`：`PiPManager.setAutoStart(false)`
   - `aboutToDisappear`：`PiPManager.unregisterPipStateChangeListener()`

8. **修改 `AVPlayer.ets`**
   - 这是核心改动：当前 `build()`（608-911）直接渲染 `XComponent({type: SURFACE, controller})`。改为：**移除直接 XComponent，由 PlayerPage 通过 NodeContainer 注入 typeNode**
   - 但 AVPlayer 还有很多基于 XComponent 的逻辑（onLoad 注入 surfaceId、onAreaChange resizeSurface、手势、控制层）。需要重构：onLoad/onAreaChange 逻辑迁到 CustomXComponentController.onSurfaceCreated + XCNodeController 的尺寸监听
   - **实施策略**：AVPlayer 的 build 渲染层用一个 `NodeContainer`（接收 PlayerPage 传入的 xcNodeController），其它控制层/手势层保持不变（它们叠在渲染层之上，不依赖 XComponent 对象本身）
   - onAreaChange 的 resizeSurface：在 NodeContainer 的 onAreaChange 里调 `controller.resizeSurface(pxW, pxH)`

9. **修改 `PlayerSession.ets`**
   - `private _isPiPActive: boolean = false` + getter/setter（setPiPActive 由 PiPManager.onStateChange 调用）
   - `release()`：若 isPiPActive，先 `PiPManager.stopPiP()`

### 阶段 3：交互接入

10. **修改 `Index.ets` onBackPressed**（1387-1400）
    - 优先级链：评论回复展开 > 沉浸全屏 > **(pipOnReturn && PlayerState在播放/暂停 && !isPiPActive && PiP已init && isPiPEnabled) ? startPiP : 现状退出**
    - startPiP 触发后**不 pop 播放页**（保留占位层），不 release
    - 若全屏中先 emit(EXIT_FULLSCREEN) 再 startPiP

11. **修改 `VideoDetails.ets`**（350）
    - "后台播放"按钮：改为 `ctx.moveToBackground()`（实施时核查 API；永远回桌面保活，不碰 vo，不弹 PiP）

12. **修改 `PlaybackConfig.ets`**
    - 新增 `pipOnReturn: boolean = true`
    - 设置页"播放设置"加开关"返回时进入画中画"

13. **修改 `ActionHub.ets`**
    - `enterPiP` / `exitPiP`（exitPiP 对应 PiP 控制面板恢复按钮 → 系统自动处理还原，无需手动；预留接口）

### 阶段 4：配置与验证

14. **`module.json5`** PiP 能力声明核查（对照官方文档确认是否需要 metadata；PiP 在 API 12+ 一般靠 PiPConfiguration 配置，无需特殊 metadata，实施时确认）

15. **资源文件**
    - str_pip_setting_onreturn("返回时进入画中画")、str_pip_placeholder("画中画播放中")、str_pip_restore("点击恢复")

16. **边界处理**
    - `PiPWindow.isPiPEnabled()` 检测设备支持，不支持时隐藏设置项 + pipOnReturn 强制 false
    - PlayerState 必须 PLAYING/PAUSED/BUFFERING/READY 才允许 startPiP，否则跳过
    - PiP 中切歌：updateContentSize 更新 + controller 单例不变（surfaceId 由 onSurfaceCreated 自动）
    - 横屏视频：PiP 窗口按 contentWidth/Height 自动算比例（letterbox）
    - setAutoStart=true 时确保页面是 PlayerPage（onHidden 已设 false，避免非播放页 home 键误启 PiP）

| **AVSession不受影响** | PiP 激活时操作 AVSession | 行为一致 |
| **设备不支持PiP** | 不支持设备 | isPiPEnabled=false；设置项隐藏 |

`build` agent 执行：先 `check_ets_files` 过编译；真机先验证"回归-后台保活"确认现状无破坏，再验证 PiP 全流程。重点用 hilog 观察 PiPWindow tag 的 stateChange 序列、mpv tag 的 setSurfaceID 调用。

## Risks And Compatibility

| 风险 | 影响 | 缓解 |
|---|---|---|
| **AVPlayer.ets 重构风险** | 从直接 XComponent 改为 NodeContainer 是较大改动，可能影响现有 onAreaChange/手势/控制层 | 控制层/手势层不依赖 XComponent 对象本身（叠在渲染层之上的独立组件），只需把渲染层从 XComponent 换成 NodeContainer；onAreaChange 用 NodeContainer 的；先做编译验证再真机 |
| **typeNode 创建时机** | 必须主窗口 UIContext，时序错会失败 | EntryAbility.onWindowStageCreate 拿到 UIContext 后立即创建（参考官方 EntryAbility 示例） |
| **navigationId 还原** | 还原场景恢复页面依赖 navigationId | Index.ets HdsNavigation 必须设 id；config.navigationId 传该 id |
| **mpv wid 切换黑帧** | typeNode 迁移时 surfaceId 变化，mpv 切 wid 可能短暂黑屏 | onSurfaceCreated 回调立即 setSurfaceID，实测确认；mpv attachSurface 已设计为可重入 |
| **setAutoStart 时序** | home 键场景由系统处理，但若页面非 PlayerPage 时误启 | onShown 设 true、onHidden 设 false，确保仅播放页可见时允许 |
| **设备不支持 PiP** | 低版本/PC 无 PiP | isPiPEnabled 检测，失败则隐藏设置项 + pipOnReturn=false |
| **控制面板事件类型** | PiPControlType/ControlEventParam 枚举按官方文档使用 | VIDEO_PLAY_PAUSE/VIDEO_NEXT/VIDEO_PREVIOUS 是 VIDEO_PLAY 模板标配 |
| **moveToBackground API** | "后台播放"按钮实现 | 实施时核查 UIAbilityContext API |
| **module.json5 PiP 声明** | 可能需要 metadata | 对照官方文档核查 |
