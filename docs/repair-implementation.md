# YourPipe 修复实施与验收记录

日期：2026-10-24。代码修复已落地，模拟器基础验收已完成，真机关键路径待验收。本记录对应此前修复书的 R01—R21；没有把静态检查或模拟平台测试等同于真机验证。

## 已落地的行为

| 范围 | 修复前 | 当前实现 |
| --- | --- | --- |
| R01—R02 代理 | ArkWeb 回调未结束就报告完成；桥失败可能清掉代理并直连 | 不可变配置快照、修订号与 disabled/applying/ready/blocked 状态；等待有界原生回调；失败保留拒绝转发的本地入口；netstack、RCP、MPV 检查可用性；登录 WebView 和媒体缩略图增加门控；连接测试只提交当前配置结果 |
| R03 Cookie 导入 | 验证前覆盖账号，联网失败后退出旧账号 | 候选使用隔离 downloader 做只读验证，成功后先完成持久化再发布；验证或保存失败保持旧 Cookie、OAuth 和隐私开关；离开页面或账号变化后不提交候选 |
| R04—R05 账号与缓存 | auth 分区不能区分账号，旧请求可回填缓存及云端数据 | 显式凭据修订号、用户数据上下文、端点身份与缓存代次；预取、Set-Cookie、token 刷新、设备登录、云端合并检查归属；账号替换使 visitor/PoToken 失效；SABR lease 不跨账号复用 |
| R06—R07 页面与队列 | 旧响应、token 或 finally 可能覆盖新操作 | 搜索、建议、频道各 Tab、播放列表、评论及回复增加请求归属；队列重建/清空使旧分页失效；离开后旧请求不能提交 |
| R08—R09 播放 | 连续切换可能最后加载旧源；旧播放状态覆盖暂停；订阅进度收到原始零值 | 候选源独立拥有会话，最后一次有效选择才提交；旧候选只回收自己的资源；遵守最新用户/系统播放意图；同媒体重载的规范化时间轴同时发给 VM、进度订阅和 AVSession |
| R10—R12 聊天、翻译与反馈 | 聊天首次失败后不再初始化；翻译上下文混用；回复/分页失败不可见 | 无 continuation 重试 initial，有 token 才 poll；译文绑定文本、语言和服务修订号，服务改变通知观察状态失效；回复与分页错误保留内容并提供重试；评论空页追取有界 |
| R13 下载 | 暂停后立即恢复会撤销旧任务的取消标记；删除/清除可能早于写入退出 | 请求登记真实中止句柄；继续等待旧尝试退出后才使用新流；合并后检查取消；删除及清除等待资源所有者退出；SABR 中止独立下载 lease 的在途 POST |
| R14 本地文件 | 大文件同步复制阻塞界面；清除期间可能登记旧导入 | 导入、导出及单轨复制使用异步文件接口；完整复制后逐个登记；显示部分失败数量；清除等待在途复制、清理未提交文件及无索引残留 |
| R15—R16 持久化 | 收藏/队列恢复遗漏字段；设置逐字段 flush | 显式 VideoItem 映射保留 Shorts、时长、会员/认证、精确观看数、本地路径等字段，派生过滤标记重算；旧记录兼容；同一逻辑更新合并 flush，恢复流程可等待并接收失败 |
| R17 URL 与资源 | HLS 手工拼接；封面异常出口可能漏释放 | 使用系统 URL 相对解析；请求、图片源及文件在结束路径释放；封面提交受元数据代次约束 |
| R18—R19 恢复与清除 | 提前提示成功，运行配置可能落后，旧工作可能重新写入 | `SettingsRuntime` 统一重应用端点、翻译、主题/语言及代理；恢复/清除等待必要存储与运行时完成；`AppDataEpoch` 拒绝恢复前及恢复中的旧提交；清除停止播放/队列，等待下载和导入，再删除用户媒体 |
| R20 响应式与职责 | 搜索页面同时拥有请求、分页与渲染 | `SearchViewModel` 通过 `@Observed`/`@Track` 拥有结果、分页、错误和建议，页面保留输入、键盘和导航；沿现有模块边界渐进整理，未进行全仓 V2 迁移 |
| R21 功能保留 | 未调用、停用或较大代码可能被误判为冗余 | 保留 MPV/FFmpeg、SABR/UMP、代理桥、ASR、Shorts、字幕和实验功能、静态 DASH 回滚及后台/PiP 路径；仅去掉机械重复注解和无用导入，并替换有缺口的 URL 拼接 |

## 验证证据

- 行为回归：23 项通过。执行的是实际 ArkTS 服务源码，平台依赖由可控适配器提供。覆盖响应乱序、凭据存储失败、代理原生回调缺失、暂停时没有字节回调、恢复写入屏障、导入复制与清除并发、字段往返和 IPv6/相对 URL 等。
- 完整产品构建：交付版本 `devecocli build` 通过。没有以单模块构建代替跨模块验证。
- API 26 平板模拟器：`devecocli run --skip-build` 返回 `Smoke: PASS`；首页实际加载，搜索词输入、历史词搜索、按钮重复提交与滚动分页均已操作，结果追加至第 49 项以上，页面保持前台。首次搜索曾暴露 ViewModel 的 `feedSource` 漏标 `@Track`，已修复、重建、重新部署并复测通过。模拟器恢复停止状态，仅删除本次测试新增的搜索历史，未卸载应用或清除用户数据。
- ArkTS 静态检查：本次变更无新增编译错误；工具仍报告既有的 `DownloadPage` regular task → `@ObjectLink` 诊断，完整产品编译将其列为告警。
- Lint：三个模块已执行。仍有 14 条 `@typescript-eslint/await-thenable` 错误，逐条对照 HEAD，相关等待表达式均已存在。未通过删除 Promise 等待或关闭规则消除报告；因此不宣称 lint 全绿。另有既有性能/平台/弃用告警。
- `git diff --check` 已通过；CodeGraph 已增量同步。
- 构建环境存在旧 Hvigor daemon 连接记录故障。验证时临时关闭 daemon，结束后按原始字节恢复配置，没有永久修改构建策略。

回归入口：[`tools/tests/README.md`](../tools/tests/README.md)。主要新增所有者：`SearchViewModel`、`SettingsRuntime`、`AppDataEpoch`、`VideoItemPersistence`、`PlaybackTimeline`。各模块 AGENTS.md 已同步维护持久架构约定。
